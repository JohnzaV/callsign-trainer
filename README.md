# Callsign Trainer CZ

Offline webová aplikace pro procvičování ICAO kódů a radiotelefonních volacích znaků aerolinek, které létaly na LKPR, LKTB, LKMT a LKKV.

## Spuštění

Rozbalte ZIP a otevřete `index.html` v libovolném moderním prohlížeči. Není potřeba instalace ani připojení k internetu. Pokrok se ukládá lokálně v daném prohlížeči.

## Úprava databáze

Data jsou v souboru `airlines.js`. Každá položka obsahuje název aerolinky, ICAO kód, volací znak a pole letišť.

Poznámka: databáze je praktický výukový výběr pravidelných a opakovaných charterových dopravců z roku 2025, nikoli úplný výpis všech jednotlivých pohybů.
